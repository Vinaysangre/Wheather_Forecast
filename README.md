# 🌦️ Weather Forecast Dashboard

## 🚀 Project Overview

This project focuses on analyzing and visualizing **weather and air quality data** using Microsoft Power BI. The dashboard provides an interactive view of current weather conditions, short-term weather forecasts, precipitation, temperature, wind speed, humidity, visibility, pressure, UV index, and air quality indicators.

The goal of this project is to transform weather data into an easy-to-understand interactive dashboard that helps users explore **current weather conditions, forecast trends, rainfall probability, and air quality information** based on the selected location.

---

## 🛠️ Tools & Technologies

* Microsoft Power BI
* DAX
* Data Modeling
* Data Visualization
* Interactive Slicers & Filters
* Weather & Forecast Data
* Power BI Dashboard Design

---

## 📌 Key KPIs Analyzed

The dashboard provides important weather and environmental indicators including **Current Temperature, Humidity, Wind Speed, Visibility, Atmospheric Pressure, Precipitation, and UV Index**.

It also provides air quality indicators such as **CO, NO₂, O₃, PM10, SO₂, and PM2.5**, allowing users to monitor both weather conditions and environmental quality.

---

## 🌡️ Current Weather Analysis

The dashboard provides a real-time-style overview of current weather conditions for the selected location.

Users can analyze **current temperature, weather condition, humidity, wind speed, visibility, pressure, precipitation, and UV index** through interactive KPI cards and visual indicators.

A location slicer allows users to select a specific location and dynamically update the weather information displayed on the dashboard.

---

## 📅 Weather Forecast Analysis

The dashboard includes a day-wise weather forecast that allows users to analyze expected temperature changes across upcoming days.

The forecast analysis includes:

* Average Temperature
* Day-wise Temperature Trends
* Chance of Rain
* Daily Rainfall Probability
* Sunrise Time
* Sunset Time

Interactive day filters allow users to focus on specific forecast periods and explore changes in weather conditions over time.

---

## 🌧️ Rainfall & Precipitation Analysis

The dashboard provides analysis of **precipitation and chance of rain** using forecast data.

A visual comparison between rainfall-related metrics and daily rain probability helps users understand expected rainfall patterns across the forecast period.

This analysis can help users identify days with a higher probability of rainfall and understand upcoming weather conditions.

---

## 🌬️ Weather Condition Analysis

Important atmospheric indicators such as **humidity, wind speed, visibility, atmospheric pressure, and UV index** are displayed through dedicated KPI cards.

These indicators provide a comprehensive overview of environmental conditions for the selected location.

---

## 🌫️ Air Quality Analysis

A dedicated section of the dashboard focuses on **Air Quality Index and pollutant-level analysis**.

The dashboard tracks major air pollutants including:

* **CO** — Carbon Monoxide
* **NO₂** — Nitrogen Dioxide
* **O₃** — Ozone
* **PM10** — Particulate Matter
* **SO₂** — Sulfur Dioxide
* **PM2.5** — Fine Particulate Matter

The dashboard also includes a PM10-based visualization to provide a clearer representation of air quality composition.

This section helps users understand environmental conditions alongside weather information.

---

## 🔍 Key Insights

The dashboard provides a centralized view of **current weather conditions, forecast trends, rainfall probability, and air quality**.

Users can monitor temperature changes across forecast days, identify periods with a higher chance of rain, and evaluate environmental conditions using humidity, wind, visibility, pressure, and UV indicators.

The air quality section provides additional insights into pollutant levels such as **PM2.5, PM10, CO, NO₂, O₃, and SO₂**, making the dashboard useful for both weather monitoring and environmental analysis.

## 🧮 DAX & Data Modeling

**DAX (Data Analysis Expressions)** was used to create dynamic measures and KPIs for the dashboard.

Custom calculations were used for weather metrics, forecast analysis, air quality indicators, and dynamic dashboard elements.

**Data Modeling** was used to organize current weather, forecast day, forecast hour, location, and measure-related data to support interactive filtering and visualization.

The project demonstrates how Power BI can combine multiple weather-related data structures into a single interactive analytical solution.
